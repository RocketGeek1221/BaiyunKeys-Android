# v1.0.2 — 固定签名 + 应用内检查更新

> ## ⚠️ 本版是「卸载重装」版，先备份再动手
>
> 这是本项目**最后一次需要卸载的版本**。从 1.0.3 起可以直接覆盖升级、数据保留。
>
> **为什么必须卸载**：1.0.2 之前的包用的是每次构建随机生成的 debug 签名，本版换成固定签名，
> Android 不允许「包名相同、签名不同」的包覆盖安装（`INSTALL_FAILED_UPDATE_INCOMPATIBLE`，
> 小米上会提示「与已安装应用签名不同的应用包」）。
>
> **卸载会清空应用数据**：门禁列表用 Android Keystore 加密落盘，密钥随卸载一起销毁，
> 系统备份、换机助手都恢复不了。**App 内导出的文本 / 二维码是唯一可迁移的备份。**
>
> ### 升级步骤（照着做）
>
> 1. 打开 App → **配置** → **导出**（文本或二维码），核对门禁齐全，存到手机或截图；
> 2. 卸载旧版本（小米「应用双开 / 手机分身」是独立空间，需要分别导出、分别卸载）；
> 3. 安装本页的 `BaiyunKeys-Android.apk`；
> 4. 配置页 → **导入**，粘贴文本或扫码，确认门禁都回来了；
> 5. 打开「配置 → 关于 → 检查更新」验证一下联网是否正常。
>
> > 导出内容包含明文的门禁 Key，等同于实体钥匙，请勿外传。

## 新增：应用内检查更新

- 冷启动时检查一次 GitHub 上的最新**正式版**（6 小时内不重复），有新版本弹窗提示；
- 「配置 → 关于」里的版本号旁边也能手动检查；
- 「立即更新」打开浏览器下载 APK，App 自己不写下载器，因此**不需要存储权限和安装权限**；
- 更新说明会显示在弹窗里（发版说明写什么就显示什么）。

## 修复

- 补上 `android.permission.INTERNET`：「自动获取配置」此前必然失败
  （`SocketException: socket failed: EACCES`），三条通道全部受影响。蓝牙离线开锁不联网，不受影响。#1

## 隐私：会联网，但只有两处

| 场景 | 请求 | 携带信息 |
|---|---|---|
| 检查更新（冷启动 / 手动） | `api.github.com` 查询最新 Release | IP、User-Agent；**没有账号、没有 cookie、没有门禁数据** |
| 自动获取配置（你主动触发） | 官方接口拉门禁列表 | 手机号 / OpenID 等你自己填的凭据 |

- **不想让它自动联网**：设置 → 联网与隐私 → 关闭「检查更新」，冷启动就零请求
  （手动点「检查更新」仍会发一次，因为那是你主动要求的）。
- 除此之外全部本地离线：开锁、扫码、导入导出都不联网。
- 门禁数据始终用 Android Keystore 加密存放在应用私有目录，不上传。

## 版本
