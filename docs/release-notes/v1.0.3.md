# v1.0.3 — 网络异常说人话 + issue #1 收尾

> ## ⚠️ 从 1.0.1 及更早版本升级：同样要卸载重装，先导出备份
>
> v1.0.2 起改用**固定签名**，更早的包是每次构建随机生成的 debug 证书，
> Android 不允许「包名相同、签名不同」的包覆盖安装
> （`INSTALL_FAILED_UPDATE_INCOMPATIBLE`，小米上提示「与已安装应用签名不同的应用包」）。
>
> **卸载会清空应用数据**：门禁列表用 Android Keystore 加密，密钥随卸载销毁，
> 系统备份 / 换机助手都恢复不了。**App 内导出的文本 / 二维码是唯一可迁移的备份。**
>
> 已经在用 **1.0.2** 的：本版直接覆盖安装即可，数据不动。

## 升级方式

| 你当前安装的版本 | 怎么升级 |
|---|---|
| **1.0.1 或更早** | 配置 → **导出**（文本/二维码）→ 卸载 → 安装本版 → 配置 → **导入** |
| **1.0.2** | 直接安装，覆盖即可，门禁数据保留 |

> 小米「应用双开 / 手机分身」是独立空间，需要分别导出、分别卸载。
> 导出内容包含明文 Key，等同实体钥匙，请勿外传。

## 修复

- 网络请求失败按类型给文案，不再把 Java 异常原文甩到界面上：

  | 情况 | 现在显示 |
  |---|---|
  | 超时 | 请求超时，请检查网络后重试 |
  | 域名解析失败（GitHub 被墙常见） | 无法解析 api.github.com，请检查网络或代理设置 |
  | HTTPS 失败 | HTTPS 连接失败，请检查网络环境 |
  | socket 被拒（无网络权限） | 网络请求被系统拒绝（无网络权限或网络策略限制） |

- 「自动获取配置」与「检查更新」共用这套文案，排查时更容易分清是网络问题还是接口问题。#1

## 版本

- `versionCode 4` / `versionName 1.0.3`
- 签名：固定 release keystore，与 1.0.2 相同（覆盖安装不会冲突）
- 安装包附带 `.sha256`，可自行校验
